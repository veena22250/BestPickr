# BestPickr

BestPickr is a modern web application built using **React, TypeScript, Vite, and Tailwind CSS**.  
The project focuses on delivering a clean, responsive, and user-friendly shopping experience with fast performance and modern UI components.

---

## Features

- Modern and responsive UI
- Built with React + TypeScript
- Fast development using Vite
- Tailwind CSS styling
- Reusable component structure
- Optimized frontend performance
- Easy project setup and deployment

---

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js
- npm

## Installation

Clone the repository:

```bash
git clone https://github.com/veena22250/BestPickr.git
```

Navigate to the project folder:

```bash
cd BestPickr
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will run at:

```bash
http://localhost:5173/
```

---
