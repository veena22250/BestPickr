# BestPickr
BestPickr is a modern web application built using React, TypeScript, Vite, and Tailwind CSS. The project focuses on delivering a clean, responsive, and user-friendly shopping experience with fast performance and modern UI components.

# Features
-Modern and responsive UI
-Built with React + TypeScript
-Fast development using Vite
-Tailwind CSS styling
-Reusable component structure
-Optimized frontend performance
-Easy project setup and deployment

# Techstack
-React
-TypeScript
-Vite
-Tailwind CSS
-Node.js
-npm
